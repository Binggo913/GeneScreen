## 技术要点

### 宏观图主比对标识（任务1）
- 比对组按 `total_aln_len` 降序排列，第一个即为主比对
- 可使用 `fill` 颜色区分或添加 `stroke` 边框

### 图注勾选框（任务2）
- SVG checkbox 可用 `rect` + `polyline`（勾）实现
- 或使用 Unicode 字符 ☑ ☐

### SNP 连线（任务3）
- 需要维护 SNP 在两个轨道上的坐标映射
- 使用 `variants` 数据中的 `ref_pos` 和 `qry_pos`

### 变异数量统计（任务4）
- 从 `snps_file` 解析，按 `ref_pos` 范围过滤
- 存储在 JavaScript 变量或 HTML data 属性中

### 结果统计联动（任务5）
- 宏观图点击事件已有跳转功能，需扩展为三联动
- 预先计算每个区域的统计数据，存储在 JavaScript 对象中
- 统计卡片使用动态 DOM 更新
- 完全替换现有独立统计模块，改为区域级联动统计
