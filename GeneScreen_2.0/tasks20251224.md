# GeneScreen 2.0 Gene ID 模式上下游扩展 - 任务清单

## 功能概述

扩展 Gene ID 模式，支持提取基因上下游区域，并在可视化图中用大括号标注基因位置。

## ⚠️ 重要约束

**本次修改仅影响 Gene ID 模式，不得影响 Location 模式和 Sequence 模式的现有功能。**

- `-u` / `-d` 参数仅在 Gene ID 模式下生效
- Location 模式和 Sequence 模式的代码路径保持不变
- 所有新增参数使用默认值时，Gene ID 模式行为与修改前一致

## 📐 坐标体系约定

**为避免 off-by-one 错误，统一声明各环节的坐标体系：**

| 数据来源/环节 | 坐标体系 | 说明 |
|--------------|----------|------|
| GFF3 文件 | **1-based, 闭区间 [start, end]** | 标准 GFF3 规范 |
| 内部计算 | **1-based, 闭区间 [start, end]** | 与 GFF3 保持一致 |
| pyfaidx 提取 | **0-based, 半开区间 [start, end)** | `fasta[chrom][start:end]` |
| linkview.gff3 输出 | **1-based, 闭区间 [start, end]** | 相对坐标，与 GFF3 一致 |
| SVG 绘图 | **像素坐标** | 由 1-based 坐标转换 |

**关键转换点：**
```python
# GFF3 坐标 (1-based) → pyfaidx 提取 (0-based)
seq = fasta[chrom][start - 1 : end]  # 注意 start-1

# 相对坐标计算 (1-based → 1-based)
rel_pos = abs_pos - actual_start + 1

# 坐标转像素 (1-based, 闭区间)
# 注意：length 是闭区间长度 (end - start + 1)，需要用 length-1 确保最后一个碱基映射到最右端
# 特判：length == 1 时直接取 padding（避免除以 0）
if length == 1:
    x = padding
else:
    x = padding + (pos - 1) / (length - 1) * draw_width  # pos ∈ [1, length]
```

## 🧬 GFF 匹配规则

**Gene ID 搜索策略（保持现有行为）：**
1. 使用 ripgrep 搜索包含 Gene ID 的所有 GFF 行
2. 匹配结果包含：gene、mRNA、exon、CDS、UTR 等所有相关 feature
3. 从 `type == "gene"` 的行提取基因边界坐标（用于序列提取和上下游计算）
4. **兜底**：若无 `gene` 行，按兜底策略从 `mRNA` 行提取边界（见下方说明）
5. 所有匹配的 feature 都写入 linkview.gff3（用于可视化显示基因结构）

**多转录本处理：**
- 当前策略：保留所有转录本的注释，全部写入 linkview.gff3
- 基因边界：使用 `gene` 记录的坐标（通常是所有转录本的最大范围）
- **注意**：LINKVIEW.py 渲染时默认只展示最长转录本，但 linkview.gff3 包含所有转录本数据

**GFF 层级结构示例：**
```
gene      [start, end]     ← 用于提取序列和计算上下游
├── mRNA  [start, end]     ← 转录本（可能有多个）
│   ├── exon × N           ← 外显子
│   ├── CDS × N            ← 编码区
│   ├── five_prime_UTR     ← 5' UTR
│   └── three_prime_UTR    ← 3' UTR
└── mRNA.2 (如有多个转录本)
    └── ...
```

**strand 和边界信息来源（带兜底策略）：**
1. **优先**：从 `type == "gene"` 行获取 chrom、start、end、strand
2. **兜底**：若无 `gene` 记录，则从所有 `type == "mRNA"` 行中选取**坐标范围最大的**（即 `end - start` 最大）
3. **strand 默认值**：若 gene 和 mRNA 都无法获取 strand，默认为 `+`（正链）

### 2. SequenceExtractor 修改

**执行顺序说明：** 相对坐标计算必须基于边界裁剪后的 `actual_start`，因此需要拆分 `_parse_gff()` 的职责。

- [x] 2.1 修改 `extract_by_gene_id()` 方法签名，接收 `upstream` 和 `downstream` 参数
- [x] 2.2 拆分 `_parse_gff()` 为两个阶段：
  - **阶段1** `_parse_gff_info()`：只解析 gene_info (chrom, start, end, strand)，不生成 linkview.gff3
  - **阶段2** `_generate_linkview_gff()`：基于 `actual_start` 生成相对坐标的 linkview.gff3
- [x] 2.3 根据链方向计算理论提取区域：
  - 正链：`[gene_start - upstream, gene_end + downstream]`
  - 负链：`[gene_start - downstream, gene_end + upstream]`
- [x] 2.4 边界防御：
  - 如果 `start < 1`，截断到 1
  - 如果 `end > chrom_length`，截断到染色体长度
  - 得到 `actual_start`, `actual_end`
- [x] 2.5 修改 `_extract_fasta()` 方法，使用 `actual_start`, `actual_end` 提取序列
- [x] 2.6 计算基因相对位置（基于 `actual_start`）：
  - `gene_rel_start = gene_start - actual_start + 1`
  - `gene_rel_end = gene_end - actual_start + 1`
- [x] 2.7 调用 `_generate_linkview_gff()`，基于 `actual_start` 计算所有注释的相对坐标

**新的调用流程：**
```
extract_by_gene_id(gene_id, upstream, downstream):
    1. gene_info = _parse_gff_info(gene_id)  # 只获取基因信息
    2. 计算理论区域 [theory_start, theory_end]
    3. 边界裁剪 → [actual_start, actual_end]
    4. _extract_fasta(actual_start, actual_end)
    5. 计算 gene_rel_start, gene_rel_end
    6. _generate_linkview_gff(actual_start)  # 基于实际起点生成相对坐标
    7. 返回结果
```

### 6. LINKVIEW 可视化兼容

**坐标映射说明：**
扩展上下游后，LINKVIEW 相关文件的坐标映射关系如下：

| 文件 | 上轨道坐标 | 下轨道坐标 | 扩展后影响 |
|------|-----------|-----------|-----------|
| `.k` 文件 | `1:扩展序列长度` | `chr:比对区域` | 自动适应（从 FASTA 读取长度） |
| `.hl` 文件 | `qry_pos`（BLAST 结果） | `ref_pos`（BLAST 结果） | 自动适应（BLAST 基于扩展序列） |
| `linkview.gff3` | 相对坐标 | - | 需基于 `actual_start` 重新计算 |

**关键点：** BLAST 比对的 `qry_pos` 是相对于**提取序列**（扩展后）的坐标，不是原基因坐标。

## 数据流示意

```
命令行参数 (-u, -d)
    ↓
GeneIDProcessor (upstream, downstream)
    ↓
SequenceExtractor.extract_by_gene_id(gene_id, upstream, downstream)
    ↓
_parse_gff_info(gene_id) → 获取 gene_info (chrom, start, end, strand)
    ↓                       [优先 gene 记录，兜底 mRNA 记录]
计算理论区域 [theory_start, theory_end] (考虑链方向)
    ↓
边界裁剪 → [actual_start, actual_end]
    ↓
_extract_fasta(actual_start, actual_end) → 提取扩展区域序列
    ↓
计算 gene_rel_start, gene_rel_end (基于 actual_start)
    ↓
_generate_linkview_gff(actual_start) → 生成相对坐标的 linkview.gff3
    ↓
返回 result dict (包含所有扩展信息)
    ↓
GeneIDVisualizer.visualize()
    ↓
AlignmentVisualizer.generate_svg() → 绘制大括号标注
```
