# Implementation Tasks: Visualization Improvement (2025-12-26)

## Scope

更新 GeneScreen 2.0 可视化流程，支持参数化过滤、智能分组、多图输出、宏观概览图与交互式 HTML 展示。

## Tasks

- [x] 1. 数据结构定义

    - 字段: ref_start, ref_end, qry_start, qry_end, ref_aln_len, qry_aln_len, identity, ref_name, qry_name
    - _Requirements: 2.2_
  - [x] 1.2 定义 `AlignmentGroup`
    - 字段: chr_name, blocks, region_start, region_end, total_aln_len (LEN1 之和)
    - _Requirements: 2.2, 2.3_
  - [x] 1.3 定义 `VisualizationResult`
    - 字段: overview_path, detail_paths, detail_groups
    - _Requirements: 3.1, 4.1_

- [x] 2. LinkviewVisualizer 参数化改造
  - [x] 2.1 修改 `__init__` 添加 `min_aln_len`, `merge_gap`, `ref_index_file`
    - min_aln_len 默认 100, merge_gap 默认 1000
    - ref_index_file 用于读取染色体长度
    - _Requirements: 1.1, 2.1, 4.3_
  - [x] 2.2 修改 `generate_k_file` 使用 `self.min_aln_len` (过滤按 max(LEN1, LEN2))
    - _Requirements: 1.2, 1.3_
  - [x] 2.3 修改 `_generate_linkview_input` 使用 `self.min_aln_len`
    - _Requirements: 1.2, 1.3_

  - [x] 2.5 修改 `_extract_aligned_region_gff` 使用 `self.min_aln_len`

- [x] 3. coords 解析与分组算法
  - [x] 3.1 实现 `_parse_coords_file`
    - 解析 TSV，首行表头以 `[S1]` 开头
    - 字段顺序: S1, E1, S2, E2, LEN1, LEN2, %IDY, REF, QUERY
    - 过滤规则: max(LEN1, LEN2) >= min_aln_len
    - _Requirements: 1.2, 6.1, 6.2, 6.3_
  - [x] 3.2 实现 `_cluster_alignments`
    - 同一染色体按 ref_start 排序
    - gap < merge_gap 合并为同组
    - total_aln_len = sum of LEN1 on the chromosome
    - 返回按 total_aln_len 降序排列
    - _Requirements: 2.2, 2.3_
  - [x] 3.3 (可选) 为 `_cluster_alignments` 编写属性测试
    - **Property 2-4**

- [x] 4. 多图生成逻辑

  - [x] 4.2 改造 `generate_hl_file` 支持指定区域

  - [x] 4.3 实现 `_generate_group_visualization`

  - [x] 4.4 修改 `generate_visualization`
