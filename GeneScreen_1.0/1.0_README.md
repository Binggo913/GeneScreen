# GeneScreen 1.0

基因组比对与变异分析工具，支持多种输入模式，自动生成比对结果和可视化。

## 环境安装

### 安装 Micromamba（如未安装）

```bash
"${SHELL}" <(curl -L micro.mamba.pm/install.sh)
```

> 💡 Tip: 如果想用 `mamba` 命令代替 `micromamba`，可以添加别名：
> ```bash
> alias mamba=micromamba
> ```

更多信息参考 [Micromamba 官方安装指南](https://mamba.readthedocs.io/en/latest/installation/micromamba-installation.html)

### 创建环境

```bash
micromamba create -f environment.yml
micromamba activate genescreen
```

## 一、基因组库管理

使用 `GenomeManager.py` 管理基因组，支持自定义添加和从 IGV 下载。

基因组缓存目录：`~/.genescreen/genomes/`

### 1.1 查看已有基因组

```bash
python GenomeManager.py list
```

### 1.2 搜索 IGV 公共基因组

```bash
# 搜索水稻相关
python GenomeManager.py search rice

# 搜索人类基因组
python GenomeManager.py search human
```

### 1.3 下载 IGV 基因组

```bash
# 下载水稻参考基因组
python GenomeManager.py download IRGSP-1.0

# 下载人类基因组
python GenomeManager.py download hg38
```

### 1.4 添加自定义基因组

```bash
# 只添加基因组序列
python GenomeManager.py add Nippon /path/to/Nipponbare.fa

# 添加基因组 + 注释文件
python GenomeManager.py add Nippon /path/to/Nipponbare.fa -a /path/to/Nipponbare.gff3
```

### 1.5 删除基因组

```bash
# 删除已下载的基因组（同时删除文件）
python GenomeManager.py remove IRGSP-1.0

# 删除自定义基因组（只删除配置，不删除原文件）
python GenomeManager.py remove Nippon
```

### 1.6 查看基因组详情

```bash
python GenomeManager.py info Nippon
```

## 二、使用方法

GeneScreen 支持三种输入模式：

### 模式 1：Gene ID

从参考基因组中提取指定基因，与目标基因组比对，查看基因在不同品种间的变异。

```bash
# 单个基因
python GeneScreen.py -ref Nippon -qry ZS97 -gid LOC_Os06g10990 -o output/

# 多个基因（列表文件，每行一个 ID）
python GeneScreen.py -ref Nippon -qry ZS97 -gidl gene_list.txt -o output/
```

**参数说明：**
- `-ref`: 参考基因组（用于提取基因序列，需要有注释文件）
- `-qry`: 目标基因组（比对目标）
- `-gid`: 单个基因 ID
- `-gidl`: 基因 ID 列表文件
- `-o`: 输出目录

**输出文件：**
- `{gene_id}.fasta` - 基因序列
- `{gene_id}.linkview.gff3` - 相对坐标注释
- `{gene_id}.coords` - 比对坐标
- `{gene_id}.snps` - SNP/Indel 变异

---

### 模式 2：Location（染色体坐标）

从参考基因组中提取指定区域，与目标基因组比对。

```bash
python GeneScreen.py -ref Nippon -qry ZS97 -loc positions.txt -o output/
```

**位置文件格式（Tab 分隔）：**
```
Chr1    1000000    1050000
Chr2    2000000    2100000    my_region_name
```

每行：`染色体  起始位置  终止位置  [可选名称]`

---

### 模式 3：Sequence（序列文件）

用户提供 FASTA 序列，与参考基因组比对，查看序列在参考基因组上的位置和变异。

```bash
python GeneScreen.py -ref Nippon -seq query.fasta -o output/
```

**注意：** 此模式不需要 `-qry` 参数，序列直接与 `-ref` 指定的基因组比对。

**输入文件格式：**
```fasta
>my_sequence
ATCGATCGATCGATCG...
```

如果序列文件没有 ID 行（只有序列），会自动添加默认 ID。

## 三、完整示例

```bash
# 1. 安装环境
micromamba create -f environment.yml
micromamba activate genescreen

# 2. 添加基因组
python GenomeManager.py add Nippon /data/genomes/Nipponbare.fa -a /data/genomes/Nipponbare.gff3
python GenomeManager.py add ZS97 /data/genomes/ZS97.fa

# 3. 分析基因
python GeneScreen.py -ref Nippon -qry ZS97 -gid LOC_Os06g10990 -o results/

# 4. 查看结果
ls results/
```

## 四、参数速查

| 参数 | 说明 | 必需 |
|------|------|------|
| `-ref` | 参考基因组名称或路径 | ✓ |
| `-qry` | 目标基因组（模式1/2需要） | 模式1/2 |
| `-ra` | 参考基因组注释文件（覆盖默认） | 可选 |
| `-gid` | 单个 Gene ID | 模式1 |
| `-gidl` | Gene ID 列表文件 | 模式1 |
| `-loc` | 位置文件 | 模式2 |
| `-seq` | 序列文件 | 模式3 |
| `-o` | 输出目录 | ✓ |
