## 关键修改点

### 2.1 LINKVIEW 路径
2.0 代码已使用 `os.path.join(script_dir, "LINKVIEW.py")` 指向同目录，复制后无需修改。

### 2.2 interval 导入
`LINKVIEW.py` 使用 `import interval`，通过 subprocess 以脚本方式运行时可正常工作，无需修改。

### 2.3 兼容层代码
在新 `visualizer.py` 末尾添加：
```python
class ReportGenerator:
    """兼容旧接口的报告生成器"""
    def __init__(self, output_dir: str):
        self.output_dir = output_dir
    
    def generate_report(self, result, mode, ref_name="", qry_name=""):
        if mode == "gene_id":
            viz = GeneIDVisualizer(self.output_dir)
            return viz.visualize(result, ref_name, qry_name, result.get("identity", 90), result.get("input_source"), result.get("genome_files"))
        elif mode == "location":
            viz = LocationVisualizer(self.output_dir)
            return viz.visualize(result, ref_name, qry_name, result.get("identity", 90), result.get("input_source"), result.get("genome_files"))
        else:  # sequence
            viz = SequenceVisualizer(self.output_dir)
            return viz.visualize(result, ref_name, None, result.get("identity", 90), result.get("input_source"), result.get("genome_files"))

def generate_report(result, output_dir, mode="gene_id", ref_name="", qry_name=""):
    """兼容旧接口的便捷函数"""
    generator = ReportGenerator(output_dir)
    return generator.generate_report(result, mode, ref_name, qry_name)
```
